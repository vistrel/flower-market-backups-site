Privacy Policy

How the Flower Market Backups utility uses Google Drive permissions and protects database backups.

Effective date: October 17, 2026

1. Scope of this policy

This policy concerns the private Google Drive backup integration named “Flower Market Backups.” It does not describe the complete privacy practices of the public Telegram marketplace bot, which is a separate service.

2. Information accessed

With explicit Google OAuth authorization, the backup integration can access Google Drive files and metadata as permitted by the scope approved by the account holder. Its intended operations are limited to a specified backup folder: creating and listing backup files, confirming upload success, and downloading them when restoration is required.

If a broad Google Drive permission is requested, the authorization may technically allow access outside that folder. The backup workflow is designed not to browse, download, or modify unrelated Drive content.

3. Data transferred and stored

The underlying database snapshots may contain Telegram user identifiers, contact details provided to the bot, advertisement records, moderation data, and other marketplace operational records. The backup workflow is designed to encrypt database files before they are uploaded to Google Drive. The decryption key is held separately from the stored backup files.

Google Drive stores uploaded encrypted files and related metadata according to Google's own terms. The application does not intentionally send backup data to analytics, advertising platforms, or data brokers.

4. OAuth credentials

OAuth tokens required for scheduled transfers are stored locally on the privately operated server with restricted access. They are used to authenticate API requests to Google Drive. Tokens and decryption keys are not embedded in this public website or committed to GitHub.

5. Sharing and purposes

Information is used solely to create, check, transfer, retrieve, and restore backups for operational continuity. No Google user data is sold, used for advertising, or used to train generalized AI models. Access to encrypted backups is controlled through the account's Google Drive permissions.

6. Retention and deletion

Local and remote backups are retained according to the operator's configured backup retention schedule. The authorized account holder can revoke OAuth access, remove the shared folder permission, and delete stored backup files. Revoking Google Drive authorization stops future remote access but does not by itself delete backups already stored there or on the server.

7. Security

Transfers use encrypted HTTPS connections. Before remote backup storage is enabled, the operator plans to use client-side encryption, private key storage, and backup integrity checks. No internet-based storage system can provide an absolute security guarantee.

8. Contact and updates

Questions about the integration or requests relating to its Google Drive access may be directed to the user support email shown on its Google OAuth consent screen. This document may be revised if the integration or its permissions change.
